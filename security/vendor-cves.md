# MikroTik и GitLab: покрытие CVE

Срез: 2026-10-05.

GitLab: последние четыре бюллетеня CE/EE (19.2.4–19.4.1); MikroTik: опубликованные в 2025–2026 CVE RouterOS/SwOS из NVD + CERT.PL и бюллетеней производителя. AI Gateway отдельно.

Протокольные проверки и наличие PoC: [аудит MikroTik](mikrotik-protocol-checks.md).

## Как запускать

В каталоге Web → CVE найдите `mikrotik-version` или `gitlab-version` (либо CVE ID). Выберите обнаруженный HTTP(S) сервис. Нестандартный порт берётся из выбранного сервиса/URL. Каждый шаблон подписан «потенциальный риск по версии»; в описании указаны порт GET-проверки и порт затронутой функции.

Используются только GET без учётной записи. GitLab проверяется через /help, /api/v4/version, /api/v4/metadata; RouterOS — / и /webfig/. Если сервер требует входа или скрывает номер версии, CVE не определяется. Версия из публичного ответа может отличаться от реально установленного кода после backport исправлений. Редакция EE, архитектура, firewall, туннели и включённые функции требуют подтверждения. Beta/rc исключены, поскольку числовое сравнение движка не поддерживает prerelease.

Существующие шаблоны с эксплуатацией остаются отдельными; новые проверки версии не отправляют их payload. Подбор паролей не добавляется в обычное сканирование.
