# MikroTik: протокольные проверки и PoC

Проверено по публичным материалам 05.10.2026. Наличие записи CVE, статьи или названия PoC не означает, что готова надёжная проверка. «Не найден» ниже относится к просмотренным источникам, а не к доказанному отсутствию публикаций.

## Добавленная проверка

`nmap/scripts/mikrotik-routeros-cve-2024-54772.nse` — непосредственная WinBox-проверка TCP 8291 (или выбранного порта). По умолчанию кандидат `admin`; аргумент `mikrotik-routeros-cve-2024-54772.username` задаёт другое имя. Делает три пары запросов на отдельных соединениях, чередует порядок, читает полные фреймы. Подтверждение требует трёх ответов 51 байт для кандидата и 35 байт для трёх случайных контролей.

При таймаутах, неизвестном формате, одинаковых ответах или отсутствующем кандидате выводится UNKNOWN. Это не доказательство исправления. Проверка относится к vuln/auth и «Активные проверки»: три контрольные пары без словаря — ограниченный дифференциальный метод, а не подбор. Попытки аутентификации сохраняются как отдельный признак воздействия. Исходная `mikrotik-routeros-username-brute` также перенесена из discovery в единственную категорию brute.

Алгоритм добавлен по документированному PoC; проверка на паре уязвимого и исправленного устройств не проводилась.
